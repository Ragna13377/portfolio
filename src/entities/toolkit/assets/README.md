These SVG paths and hex colors are copied without modification from the official
[Simple Icons](https://github.com/simple-icons/simple-icons) npm package, version
16.34.0. The CC0 license is included in SIMPLE-ICONS-LICENSE.md. Only the glyphs
used by the Toolkit are bundled; there is no CDN or runtime package dependency.

TanStack Query uses the TanStack glyph; Three.js / React Three Fiber uses the
Three.js glyph. Zustand is absent from this catalog and uses a neutral `Zu`
text mark. Tiles use a dark background. Glyphs with insufficient contrast use
a light monochrome treatment, while their brand accent color stays unchanged.
